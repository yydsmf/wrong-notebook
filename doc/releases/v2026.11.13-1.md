# 家庭学习定制版首次预览发布

本版本来自 margrop/wrong-notebook，保留其完整提交历史，发布代码采用当前家庭学习定制版本的完整快照。应用基于上游提交 `3a70f83b` 开发；后续上游重构保留在历史中，其功能需要另行合并与验证，不代表已包含在本版本中。

## 本次内容

- 管理员维护题库和试卷；普通用户共享管理员题库与试卷，答题结果和复习进度分别保存。
- 简化学生界面，支持复习和试卷中的选择题、判断题及手写答案上传，提交后由 AI 批改并提供错因分析。
- 支持裁剪前手动旋转照片，强化原题逐字转录及单位、公式、上下结构填空的保真处理。
- 上传识题时停用 SVG 画图；导入后支持多次裁剪、上传原图配图，改写题目避免直接复用不匹配的来源题图。
- 后台 AI 调用使用流式接收，展示处理阶段和进度；失败任务支持重新生成。
- 改善中文下划线、数学符号及分数填空显示，补充数据库迁移和备份格式支持。

## 发布说明

- GitHub Release 和容器发布目标为本仓库，日期标签为 `v2026.11.13-1`，不修改 `package.json` 版本号。

- AI 识别和批改结果仍需按实际题目核对，本版本不保证所有图片和手写答案都能准确识别。
