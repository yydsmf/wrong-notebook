# 结构化配图长期优化记录

## 目标和边界

目标是让小学、初中常见数学配图可重复、可验证地生成。AI 负责输出结构和标注，本地模板负责坐标、排版和 SVG；模板绘制不增加 AI 请求，也不需要额外的生图服务。

这是一项持续优化工作。通过模板测试不等于真实拍照识别已经准确，也不等于复杂图形全部可用；没有定时或离线自动开发任务。

上传识题仍保留原图与图形说明，停用该环节的 SVG 生成。结构化管线用于已有的 AI 配图生成、举一反三和新题配图流程，不自动复用旧题图作为新题图。手动配图和原图核对继续沿用应用现有流程。

## 支持范围

| 类型 | 当前模板 | 主要限制 |
| --- | --- | --- |
| `vertical_arithmetic` | 加、减、乘、整数除法竖式，部分积、逐步减数、商、余数、占位和标注 | 只复算已有纯整数，不填作答空格；整数和简单未知数字按固定数位锚点排版；不含部分积且结构明确的加减小数按小数点对齐，结构明确的乘法小数按末位数字对齐且小数点不占数字列；乘法位移不得超出整数／小数乘数的数字位；除法要求逐步减数明确给出 `shift`；说明最多三行，超容量回退；除法小数和复杂表达式仍保留整行文字 |
| `fraction` | 上下分数、分数条、分数圆、带分数图示 | 分数条最多 40 份，分数圆最多 24 份；涂色图要求明确非负整数分子、分母及一致的分割／涂色数据；图示的整数部分为 0～5，超限或不明确时回退；上下分数文字不受此图示数量限制 |
| `number_line` | 数轴、刻度和点标注 | 十进制精确生成最多 25 个刻度，保留小数值与可达刻度端点；相邻标签统一尝试 18px 至 12px 并留 2px 间隔，仍拥挤时整图回退；明确的点名数值声明会与可见同名点交叉校验 |
| `coordinate_plane` | 坐标轴、点、线段和文字 | 十进制精确生成最多 25 个刻度，不舍入小数标签或重复数值；使用相同的横纵单位比例，间隔过密时回退，非方形范围会留白 |
| `circle_geometry` | 圆、半径、直径、弦、劣弧、优弧、半圆和扇形 | 核对明确弦长的直径上限及同端点标注；不按示意角度求弦长。优弧用 `arcType: "major"`；直径端点或接近直径时必须用 `through` 指明半圆方向并省略弧型，关系不确定就回退 |
| `area_geometry` | 三角形、长方形、正方形、平行四边形、梯形及高 | 三角形的高可落在底边、端点或延长线上，四边形支持外部高；同步绘制底边延长虚线，底长不含延长部分；核对明确等腰、等边、直角声明；尺寸和直角标记统一避让，标题独立排版、最多三行，模板字号至少 12px；固定结构模板，不代替任意复合图形 |
| `solid_geometry` | 长方体、正方体和遮挡线 | 尺寸关联对应棱并避让可见棱和遮挡棱，标题独立排版、最多三行，模板字号至少 12px；固定透视示意，不承诺所有投影与展开图 |
| `stacked_solid` | 两个上下居中叠放的长方体 | 只支持两个规则长方体，顶物体的长和宽不大于底物体；固定轴测投影和尺寸标注；识别“两个长方体上下叠放”及“一个长方体放在另一个长方体上”等明确主图声明，题干给出底层／上层尺寸时分别核对长、宽、高，不允许另一层的标注代替；顶层共线长度标注最低可降到 12px，仍无法排版时整图回退；不支持悬空、错位、挖空、左右拼接、多个组合体或展开图，无法确认时回退 |
| `solid_net` | 六个同样大小正方形组成的正方体展开图 | 只接受能通过六面折叠校验的六格布局；每格可保留面内印刷标签；不表示长方体、组合体或带复杂尺寸线的展开图，无法确认拓扑时回退完整旧 SVG、原图或手动配图 |
| `round_solid` | 正圆柱、正圆锥、椭圆底面及隐藏弧 | 轮廓按相对半径和高投影，圆锥斜边与底面椭圆相切；半径、直径、高使用独立尺寸线，母线沿斜边标注；核对已知长度关系及明确题干尺寸；极端比例或标注排不下完整回退，不支持斜立体、圆台、展开图和组合体 |
| `basic_geometry` | 点、线段、多边形、圆、角和直角符号 | 检查引用、退化、自交、重合点和直角；明确主图的单个多边形或唯一实线闭合环核对边数、平行、垂直、正方形等边、三角形子类型及完整边标注，明确三角形三边同类单位可比较时精确核对严格三边不等式；混合圆和辅助线时有限核对半径、弦、直径、圆心角和圆周角；几何点名、长度和角度标注低于 12px 无法可靠排版时整图回退；圆弧方向和扇形区域仍使用专用圆图模板 |
| `bar_chart` / `line_chart` | 单组柱状图、折线图 | 柱状图保留 0 基线，柱顶数据值与柱体、分类文字、标题、单位和坐标轴共同避让；折线图尊重实际数据及明确的 `minValue` / `maxValue`，数据值与线段、数据点、分类文字、标题和坐标轴共同避让；原图纵轴刻度清楚时可保留 `tickStep`，刻度文字固定排在纵轴左侧并参与避让；分类文字最多三行，数据值、单位、标题和刻度低于 12px 或范围／布局冲突时整图回退；多组数据尚未支持 |
| `grid_shape` | 方格涂色与格内文字 | 最多 30 × 30；保持正方格，格内最多三行，字号至少 12，画布高度最多 800；超出可排版范围时回退 |
| `table` | 表头、数据行和标题 | 最多 12 列、30 行，每格最多三行，表头与正文至少 12px，画布高度最多 800 |
| `figure_group` | 同题的独立子图、A/B/C/D 选项图 | 2～6 图，不递归；逐图结构校验；题干仅在全部标签有明确独立子句时才做对应语义交叉校验，整体失败则整组回退；不能验证模型是否漏认原图中的某个选项 |

圆图和坐标图的长标题超过图宽对应的单行范围时，使用独立标题区，按完整图文宽度最多分三行、模板字号至少 12px。下方内层 SVG 保持原始坐标、画布、字号和比例，外层只安排标题与图形占位；内层仍接受原有几何及 800×500 边界校验，外层标题画布高度最多 800。完整标记无法容纳时整图回退。短标题继续沿用原有布局；可可靠测量的 SVG 在 100% 显示比例下保留至少 12px 的阅读字号，用户缩放后的实际字号仍须单独检查。

明确的中英文菱形主图声明也使用现有几何模板校验：通用几何的四边须等长、两组对边须平行，正方形可满足条件；具名声明仍检查可见顶点的边界顺序。完整边标签精确比较，分段、对角线和内部高不当作边长。简单底高图可沿用 `area_geometry` 的 `parallelogram`，其相对斜边长度须与底相等；垂直高单独保留与核对，不按绘图尺寸推算物理长度。没有新增 `rhombus` 模板类型或 `shape` 枚举。多个主图、疑问、假设、证明或候选说法继续沿用保守边界，明确冲突时整图或整组回退。

### 图组契约

`figure_group` 使用 `{type, title?, compareSizes?, figures:[{label, figure}]}`。每个 `figure` 只能是上表中的单图类型，标签规范化后不能为空或重复，点引用只在所属子图内生效。若题干明确按全部子图标签分段（如“图A中……；图B中……”“选项A：……；选项B：……”或“(A)…；(B)…”），程序逐段只对照对应子图，并对该范围内的点名、线段、角、圆关系、主图形状和算式执行已有校验；点名引用在此显式范围内全部缺失也会回退。形似几何点名的拉丁标签（如 `A`、`A1`、`A₁`、`A′`）必须有标点、括号或“图／选项”前缀，不能仅凭标签后的空格分段，以免把点名当成子图标签；非点名型中文标签仍支持空格分段。选择／判断／真假题、引用、假设或其它不确定语境，以及没有完整、唯一标签分段的普通比较题不启用该校验，避免把待判断选项或整题条件误认为每张图的事实。已有新题生成仍按原规则只生成无选项的填空或解答题，不因图组支持而改为生成选择题。

图组宽度 800、高度最多 1800，优先两列，字号不足时尝试单列；所有子图共用同一像素缩放，不拉伸、不单独放大。图组外层标题使用 22px 模板字号，最多三行，行间距为字号的 1.35 倍；标题新增的行高计入选项与子图位置及 1800px 总高度限制，不挤占选项标签。数值与紧连单位保持完整，超宽标记不拆行。缩放后的模板字号至少 12；可可靠测量的图组在 100% 显示比例下保持阅读尺寸，宽图或高图在局部区域内滚动，也可查看大图。标题放不下、任一子图无效或整体排版超限时不输出部分图组，继续尝试完整旧 SVG；没有可用旧 SVG 时不返回配图，保留现有原图和手动配图核对流程。

如果答题需要比较不同子图的实际大小，模型必须设置 `compareSizes: true`，所有子图使用统一的 0～100 坐标单位及明确的相对尺寸，类型限 `basic_geometry` 或 `circle_geometry`。基础几何中的圆半径至少 1，避免其既有模板限幅改变小圆比例。面积、立体、坐标等模板会独立适配画布，不能建立跨子图的尺寸比例；程序也无法从遗漏的 `compareSizes` 或模型错误坐标中推断真实比例。

## 校验和回退

1. `src/lib/figure-spec.ts` 解析 `<figure_spec>` JSON，执行 Zod 与语义校验，归一化文字及算式。
2. 合法描述进入本地模板，再做 SVG 净化、无效数值及几何边界检查；失败返回 `null` 和不含题目原文的诊断原因。图组的每张子图保留原单图数值及边界检查，外层排版单独校验，不因组图更高放宽子图的检查范围。
3. `src/lib/ai/schema.ts` 的 `parseFigure()` 优先使用结构化结果，否则尝试旧 `<figure_svg>`；均不可用时不返回配图。
4. 旧 SVG 只经过安全净化，不能据此判断数学关系正确。原图供管理员核对，必要时使用手动裁剪上传功能。

竖式复算只作用于已有的纯整数部分积和结果，不能替换方框、问号、下划线、未知数字、字母或表达式，也不创建原图没有的结果行。乘法的 `shift` 省略时按行号从 0 递增，未知被乘数仍保持此规则；跳过乘数中的 0 需显式给出真实数位。重复数位、或超出已知整数乘数位数的部分积，视为语义校验失败，单图或整组回退。未知乘数不凭空推断位数。这只能防止结构化处理改变作答状态及明显无效的数位引用，不能验证模型转录的因数、题干或原图是否一致。

服务端可用 `STRUCTURED_FIGURE_DIAGNOSTICS=1` 开启结构化回退的调试日志；日志仅记录失败原因和类型。

## 每轮验收

- 有效样本：保留完整文字和数字，输出确定，关键图元存在。
- 错误样本：矛盾数据、无效引用和无法可靠排版的描述应回退，不截掉关键文字。
- 浏览器：SVG 可解码、尺寸非零，桌面和手机页面不横向溢出；用 `getBBox()` 检查文字在画布内，表格文字在所属单元格内。
- 涂色模型：用画布像素检查应涂和不应涂的区域，避免 SVG 语法正确但实际空白。
- 修改逻辑后执行单元、集成测试；针对渲染改动追加相关浏览器测试。测试通过后不重复无关构建。

npm run test:unit
npm run test:integration
npm run lint
npx tsc --noEmit --incremental false
