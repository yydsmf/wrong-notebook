# 错题管理指南

旧安装的管理员仍使用默认密码时，先在安装向导完成改密。向导可读取安装状态，受限API返回JSON错误而不跳转成网页；后台任务按钮在向导和改密前隐藏。

## 创建错题本

创建错题本时选择学段（小学、初中或高中）和学科。学段与学科决定 AI 使用的知识点库，创建后不可修改，建议按学习阶段和学科分别管理。

小学可选数学、英语和语文。内置语文库覆盖小学一年级至六年级及初高中各年级的章节与知识点。升级 Docker 或安装包后，启动时会自动补齐缺失的内置语文标签，并保留旧标签 ID、题目关联、自定义标签和其他标签体系。

管理员导入「人教版课标体系」知识点后（见 [设置与用户管理](Settings-and-Users)），创建错题本时会多出「标签体系」选项。该体系与内置体系并存，创建后不可更改，AI 识别和知识点筛选只使用错题本所选体系的标签。

错题本列表只显示名称和题数，点击进入详情页；重命名和删除都在详情页进行。只能删除已清空的错题本，删除前先移走或删除其中的错题。

## 录入题目

| 入口 | 适用情况 |
| --- | --- |
| 图片上传、拖拽、拍照 | 纸质试卷、练习册和已有题目图片 |
| 剪贴板粘贴 | 已复制的截图或图片，使用 `Ctrl/⌘+V` |
| 屏幕截图 | 浏览器支持屏幕共享，且页面满足安全上下文要求 |
| 手动输入 | 已有文字题干，可使用 Markdown 与 LaTeX |
| 直接录入 | 手工整理已知的题干、答案和解析 |

图片可以先裁剪，裁剪和多题框选时可用鼠标滚轮、触屏双指捏合或右上角的按钮缩放（100%～500%，点击比例还原）；一张图片上有多道题时，可框选多题批量导入。尽量保留完整题干、必要图形和学生作答，避免模糊或裁掉条件。

一次选择多张图片时，裁剪窗口会显示当前张数，按选择顺序逐张旋转、裁剪；点击“确认并裁剪下一张”继续，最后点击“完成裁剪并导入”。默认“单题裁剪”下，所有图片共同组成一道题（例如跨页文章和问题），一次联合识别，只保存一道题及全部原图。只有主动选择“多题框选”时，各框才作为独立题目批量导入。本次模式在首张确认后保持一致；需要更改模式可取消后重新选择。中途取消会放弃尚未导入的裁剪结果。人工校对、原图查看和数据备份均保留图片顺序。

多图请求不会重复发送第一张图片，也不会额外降低图片分辨率。支持最多 20 张图片，每张编码后的传输数据不超过 20 MiB，合计不超过 50 MiB；服务端代理容量为 80 MiB，覆盖旧客户端重复首图和题目文字的传输开销。

在“设置 → 通用”开启“导入前人工确认”后，可先在校对页修改识别内容再保存。AI 可能识别错数字、符号和图形关系，保存前应核对原题。

## 学生答题与管理员查看

普通用户共享管理员题库与试卷，独立保存复习进度和答题结果。学生提交复习或试卷答案后，AI 批改并保存逐题判定与错因分析。

进入「复习」时，页面按学生复习计划只加载当前到期题目，并从空白作答开始，不会自动带入上次复习的答案、手写图片或 AI 判题结果；学生答对后按 1、3、7、14 天依次安排下一次复习，答错当天可重做。暂时没有到期题目时，页面显示最近一次复习详情；提交后当前页面也会显示这次提交的内容。试卷页面仍可恢复该试卷最近一次提交。逐题结果的「我的答案」会显示提交的文字、选项或手写图片，判分说明、错因分析、参考答案和解题说明支持 Markdown 与公式显示；参考答案和解析仅在该题批改完成后返回。历次结果由管理员在学生答题记录中查看。

管理员进入「管理后台 → 用户列表 → 查看详情 → 学生答题记录」，在「复习记录」和「试卷记录」之间切换，查看历次提交时间、批改状态、正确数与正确率。点击「查看批改」可分页查看当次提交的题目快照、题图、学生文字或选择答案、手写图片、参考答案、解题说明、判分依据与错因分析；点击手写图片可放大。

正确率只统计已经成功批改的题目，等待中或批改失败的题目不会算作答错。点击「刷新」读取最新批改状态。查看记录只读取已保存的数据，不重新调用 AI，不需要学生重新提交；修改或删除源题目后，仍可查看已保存的题目与答案快照。此入口仅管理员可用。

## 自动判重

导入时会与当前用户的已有题目比较题干，跨错题本参与判重。默认阈值为 90%，可在个人通用设置中调整。

- 相似度**严格大于**阈值时，返回已有题目，并在原题下记录一次做错。
- 相似度等于阈值时，不按超过阈值处理。
- 相似度是规范化题干后的字符编辑相似度，不代表数学含义相同。
- 重复导入记录参与后续掌握情况评估；需要核对时可查看原题的作答历史。

错题本还提供两题相似度比较，便于判断阈值是否适合自己的题目。数字或条件只改动少量字符时，相似度仍可能较高，应结合题意判断。

## 题目详情

每道题集中展示题干、答案、解析、知识点、难度、学期和卷别，并可查看拍照原图。

| 信息或操作 | 说明 |
| --- | --- |
| 6 位题目 ID | 可复制，在错题本按 ID 定位；打印中显示为来源 ID |
| 1～5 星难度 | AI 参考竞赛数学难度标准评定，可手动修改 |
| 年级/学期 | 点击「编辑年级/学期」选择并保存；校对页也可修改，加载账户资料不会覆盖手工选择 |
| 卷别 | 未指定时，1～3 星默认归入「A卷」，4～5 星默认归入「B卷」；已有手动选择优先。可在「设置 → 通用 → 卷别分组」自定义分组名称、新增分组（如单元测试、期中、期末）、停用或删除自定义分组 |
| 知识点 | 使用对应学段与学科的标签，支持单题或整本重新识别 |
| 重新生成完整解答 | 生成新的答案和解析，覆盖前会要求确认 |
| 修复 LaTeX | 检测到公式语法问题时出现，供 AI 修正公式写法 |
| 原题图片 | 可查看、替换或补充，用于核对识别结果 |

未评级的题目不会仅凭默认规则自动指定卷别。重新生成完整解答保留知识点和错因信息。

![题干、知识点、难度与试题信息](https://raw.githubusercontent.com/margrop/wrong-notebook/70b66950931f6f723083e3726fbc97f2f65d2ea8/doc/screenshots/question-detail.png)

新题目的年级可以在「设置 → 通用」选择固定或 AI 识别规则，手工选择优先，详情见[设置与用户管理](Settings-and-Users)。

## 配图和动态讲解

- **题干角度标注**：通用几何图将“∠AOB=60°”及常见英文明确度数与同顶点、同两条角边的标注精确比较；∠AOB与∠BOA视为同角，不能换顶点借用标注。重复标注须一致，直角方框对应90度。整数、小数、分数及°／度／degree(s)只用于内部比较，保存原文；未知式、角编号、约数、复合式、疑问、假设、证明及候选内容保守处理，不从示意坐标测角或补答案。明确分段的子图独立核对，冲突时保留完整旧图、原图或手动配图兜底；旧 SVG 仍需核对数学内容。
- **结构化文字可读性**：新结构化 SVG 输出前统一检查至少 12px 的模板字号，密集表格正文同样遵守；数轴相邻刻度会先尝试可读字号再判断是否回退，数轴和坐标图完整保留小数刻度与可达端点；除法竖式会为余数说明预留空间。超宽标题、单位或标注无法完整容纳时整图回退到兼容旧 SVG，无可用输出则不生成新配图，不截字或强行缩小文字。此规则不修改已有图，页面实际字号仍受显示比例和缩放影响；识图结果仍须核对原图。
- **正方体展开图**：六个同样大小的正方形只有在本地拓扑校验确认可以折成立方体时才使用固定模板；断开、重复、不可折叠或不明确的布局会保留旧图、原图或手动配图，不把长方体或组合体展开图误套入该模板。
- **展开图题干校验**：明确的“长方体展开图”会拒绝正方体展开图；“哪些展开图能折成正方体”等候选或待判断语境保持保守，不把题目要求判断的内容当成图形事实。
- **分数图示一致性**：分数条和分数圆只有在分子、分母、分割数和涂色数都是明确且相互一致的非负整数时才生成；未知量、表达式、小数或负数只保留普通上下分数结构，不能用猜测的 `parts/filled` 绘制涂色图。带分数继续保留整数单位，不能丢掉整数来换取可绘制结果；不满足条件时沿用旧 SVG、原图或手动配图。
- **题干分数校验**：题干唯一明确写出“分数为3/4”“分子是3，分母是4”或对应英文时，结构化分数会逐项核对分子和分母。候选比较、疑问、假设、引用、多组分数和复杂表达式保守跳过；明确冲突时整图或整组回退，不改写题干或分数文字，也不增加 AI 请求。
- **整数位数条件**：题干明确“两位数”等整数位数时，已知值按绝对值核对，符号和前导零不算数位，`034`、`34.0` 均按 34 核对；`3.4` 不是两位整数，微小的非零小数部分也不会被舍入掉。配图仍保留输入原文；未知数字框沿用数位检查，复杂表达式不求值、不补答案。没有明确位数条件的小数竖式继续沿用原规则，此项不提供通用小数点对齐。
- **明确度量校验**：新结构化配图会核对正方形边长、正方体棱长、矩形和平行四边形上下边、同圆半径与直径，以及直角方框的明确度数。弦长不超过同圆已知直径或半径的两倍；同一对端点的线段即使反向标注或兼作弦和直径，明确长度也须一致，不要求不同的弦等长。整数、小数、普通分数及有限带分数支持常见公制单位的精确内部比较，保存的标签保持原文。无单位数只和其它无单位数比较，未知公式和角编号不求值；相对绘图尺寸及弦的示意角度不用于推算物理长度，也不补缺失单位。矛盾时整图或整组回退，旧 SVG 只做安全净化，仍需核对题干与原图。「AI 重新生成配图」没有可用输出时保留现有配图，后台任务显示失败并可重试。
- **题干与竖式交叉校验**：唯一完整的整数、小数算式或“两位数乘25”等条件会核对数字、正负号、运算符和两边的明确位数，支持常用 LaTeX 运算符和英文运算词。题首带明确标签且完整分隔的有效日期（如“日期：2026-11-15。”）、时间范围和题号范围不当作算式；仅限连续题首信息，正文、公式、无效日期或缺少分隔的内容仍保守处理。常用无参数样式（如 `\displaystyle`）和间距命令不取消数字核对，不改写原文或忽略有参数命令中的计算结构。小数精确比较，保存的原文不改变；不会把 `3.4×25` 截成 `4×25`，也不把分数斜线当作除法。含括号复合式、连续运算、未知式或多个候选时不截取推断。发现冲突时尝试完整旧 SVG，无可用结果则不返回新配图；原图、手动配图继续保留。此检查不提供通用公式求值或小数点对齐。
- **具名主图声明**：“三角形ABC是等腰三角形”“ABCD为正方形”及对应英文写法也核对形状，支持等腰、等边、直角三角形与常见四边形。通用多边形按可见点名和边界顺序对应，区分大小写；隐藏 ID 和内部同名点不能代替顶点。循环或反向顺序可接受，交叉顺序及明确缺失点名触发整图回退。当前仅支持三个或四个单拉丁字母点名；面积、立体和坐标模板无法表达这些顶点名，不会冒充具名主图；复合图、不确定语境及选择／判断题的候选说法保守处理，原图和旧配图继续保留。
- **题干坐标校验**：坐标模板对“点A的坐标为(1,2)”及常见英文声明中的可见同名点逐项核对横纵坐标、正负号和完整有限小数，不以浮点容差忽略差异。单图没有同名点时不猜对应关系；明确按子图分段时，各图独立校验，缺失点名或冲突整组回退。变换前后、其它坐标系、相对坐标、向量、极坐标、疑问、假设、待证明、候选说法及未知表达式保守跳过；不移点、不补值，也不把通用几何的相对布局坐标当作数学坐标。沿用原图、旧图和手动配图，不增加 AI 请求。
- **题干与主图交叉校验**：使用“下图是一个正方形”或“The figure is a square”等有限的直接声明时，程序核对面积图、立体图和可明确对应的单个通用多边形，接受等边矩形和等棱长方体等兼容画法。通用多边形可旋转、反向列点、保留共线中间点和内部辅助线；只核对完整等长边标注，不把分段或对角线当作整边，不按坐标比例求实际长度或移动原始点。梯形须只有一组对边平行。求值提问仍保留形状约束；形状疑问、命题判断、待证明、假设、引用、局部图、多形状、带圆、外部独立图元及图组不推断主图归属。明确矛盾时整张结构化图回退；仍须对照原图。
- **图组选项作用域**：题干明确按“图A中……；图B中……”“选项A：……；选项B：……”或“(A)…；(B)…”分段描述子图时，程序只在对应段校验该选项的点名、线段、角、圆关系、主图形状和算式；明确缺失或冲突时整组回退。形似点名的拉丁标签（如 A、A1、A₁、A′）须有标点、括号或图／选项前缀，不能只靠空格识别，以免和几何点名混淆。比较图A和图B、下列哪项正确等未逐项分段的题目保持保守，选择／判断题中的候选说法也不作为图形事实。
- **闭合线段主图**：没有 `polygons` 时，只有所有实线恰好组成一个简单闭合环才参与题干形状校验；开链、多环或额外实线无法明确主图时保守跳过，虚线内部辅助线可以保留，不会为校验改变线段。
- **可见点名**：通用几何图、数轴、坐标图和圆图内，单个拉丁字母及数字、下标或撇号组成的可见点名必须唯一，包含圆心；全角 ASCII 和空白清理后重名会整图回退。保留大小写、下标与普通数字及不同撇号的区别，不拿说明、隐藏 ID 或其它记法推断同名，不换名、合并或移动点；不同子图可使用相同点名。
- **数轴点名**：所有点标记（包括无名点）参与文字避让和归属检查，点名不覆盖轴线、刻度或其它文字；同位置的不同点名保留并共同排版。刻度和标题保持锚点，画布按完整图文收紧留白，不移动点、删刻度或改变数值；无法可靠排版时整图或整组回退。已有配图需重新生成才使用新布局，宽图仍可在阅读区域滚动。
- **题干关系**：题目明确写出连接 `AB`、线段 `AB`、`∠ABC`、`AB∥CD` 或 `AB⊥CD` 时，程序会核对同一子图中的点名、线段、角的两条射线及平行/垂直方向；多边形边界可作为边，无法唯一解析时继续使用原图、旧配图或手动配图兜底。
- **题干点名缺失**：若关系中部分规范点名已出现在图中、其余点名缺失，程序不会静默省略而会整图回退；点名全部不在图中或无法唯一解析时继续保守跳过，避免把变量或普通文字当作几何约束。支持“连接点A和点B”等常见表达，不会补点、移动点或添加线段。
- **圆图题干关系**：题目明确写出 `半径 OA`、`弦 AB`、`直径 AB`、`连接 AB`、`圆心角 AOB`、`圆周角 ACB`、`弧 AB`、`优弧 AB`、`劣弧 AB`、`半圆 AC`、`扇形 AOB` 或对应英文表达时，程序会核对圆心、圆周点和 `radii`、`chords`、`diameters`、`arcs`、`sectors` 的结构；直径可以作为弦，普通弦不能作为直径，半径和圆心角的两条边必须连接圆心与圆周点，端点匹配的扇形也可表达圆心角，圆周角的两条边必须是实际存在的弦。两端点弧按 `arcType` 区分优弧或劣弧，三点弧名的中间点必须位于最终选定的弧段内部，可由 `through` 或 `arcType` 选择方向；半圆必须由直径端点和第三点确定方向，也支持“AB 是弦”“AB 为直径”等后置表达。无法唯一解析时不猜测补线段，继续使用原图、旧配图或手动配图兜底。
- **弧与扇形的圆心归属**：专用圆图中的弧、优劣弧、半圆和扇形也核对“圆 O 中”“圆 O 的弧 AB”或 `in circle O` 指定的圆心；范围沿逗号延续，遇到明确新圆名切换，遇到句号、分号或换行结束。弧名的两到三个点必须互不相同且均在圆周上，不能用圆心充当第三点。英文长度、面积说明不属于点名，数字、下标和撇号仍保留。方向校验只使用结构自己的 `arcType` 和 `through`；均省略时按实际劣弧核对，不借题干第三点临时改变方向。明确圆心或点名冲突时整图回退，无法唯一解释的长名称保持保守，不截取成另一条弧。通用几何仍不推断弧方向和扇形区域。
- **复合圆图题干关系**：当 `basic_geometry` 同时包含圆和辅助线时，也会核对题干明确写出的半径、弦、直径、圆心角和圆周角；圆周点须在对应圆上，具名线段必须实际画出，直径还须经过圆心。题干写出“圆O中”“在圆O内”或 `in circle O` 时，只在指定圆上核对；“内圆中”“外圆中”等写法须与已有 `circles.label` 完整且唯一匹配，不能根据半径大小补写圆名，重名对应多个圆时回退。圆名优先于仅匹配圆心点名，同一段逗号后的关系沿用当前范围，新的明确圆名切换范围，句号、分号或换行结束范围；普通多圆提及不建立归属。只写共同圆心的同心圆仍按实际半径保留候选。多边形边界也算已画出的线段。通用结构不能表达弧方向和扇形区域，这些题应使用 `circle_geometry` 或沿用原图、旧配图，不会仅凭点的位置补线。
- **三角形子类型**：主图的明确等腰、等边、直角及等腰直角声明同步核对面积模板和单个通用三角形。完整等长边须有一致标注；直角图三条完整边均有同类单位明确数值时精确检查勾股关系。未知表达式、分段、内部高、顶点说明不用于补边长或算答案，也不补单位。面积模板的 `apexRatio` 支持-1～2，0和1可让直角位于底边端点，仅此时高也是完整边；坐标有限容差不放宽数值标签的精确比较。
- **底边外的高**：三角形、平行四边形和梯形的高可落在底边延长线上，新模板同步画出虚线高、底边延长线和直角符号。延长线不占底长标注，不改写未知长度或计算答案。自动四边形底高图从外侧上顶点作高；题目若指定具名垂足或顶点，应使用通用几何图。完整图文按比例适配，过密图仍支持整图回退及原图／手动图核对；已有配图在重新生成后采用新布局。
- **三角形三边关系**：题干明确声明单个主图为三角形时，三条完整边的同类单位明确数值须满足任意两边之和严格大于第三边；例如 3cm、4cm、8cm 或 3cm、4cm、7cm 都会回退。长度在内部精确换算，标签保持原文；无单位数不借用其它标注的单位，未知边、分段和内部高不冒充整边。疑问、判断、假设和候选说法保持保守，矛盾时保留旧 SVG、原图或手动配图核对，不自动改数值或填答案。
- **菱形题图**：明确声明主图为菱形时，检查四边等长、对边平行和可见顶点顺序，正方形也可满足条件。完整边标注须一致，不将分段、对角线或垂直高当成边长；简单底高图可沿用面积模板。相对绘图尺寸不决定物理长度，题干中的边长与高分别核对已有标注。疑问、假设、证明和候选说法不强加为事实；明确冲突时整图或整组回退至旧 SVG、原图或手动配图，不改坐标或填答案。
- **竖式填空**：新生成的结构化竖式保留方框、问号、下划线和未知数字，不能因已知因数而自动填出答案。乘法部分积保留甲乙标签并按数位错开；除法的逐步减数要求明确位移，并可单独保留商和余数空格；位移重复或超出已知数位时整图回退。仅对已有的纯整数结果继续复算，不能据此证明原图识别正确；旧配图不会自动修改，旧 SVG 回退也不保证数学正确。
- **竖式阅读**：新生成的竖式按内容安排紧凑画布，整数和简单未知数字按固定列对齐，方框不会因字宽不同而挤乱数位。结构明确且没有部分积的小数加减按小数点对齐；小数乘法按末位数字对齐，小数点放在相邻数字之间，不额外占一列，保留末尾零和未知方框，不复算小数或补答案。数字位数明确的乘数（包括未知格）其部分积位移不能越界，符号和小数点不计入数字位。除法使用商在上、除数在左、被除数在括号内的长除法布局，逐步减数按被除数的数位对齐，余数显示在步骤下方。说明在完整运算下方，最多三行、字号至少 12px，装不下时整图回退，不截掉说明或挤到中间。长竖式仍可滚动查看；小数除法、复杂表达式和列关系不明确的输入保留整行文字，不提供通用公式排版。旧配图重新生成后才使用新布局。
- **SVG 配图**：常见图形由 AI 识别结构后使用本地模板生成静态 SVG，供详情、练习和打印使用；原图可单独查看。题目配图提供「查看大图」按钮，手机上可在大图弹窗中通过按钮、滚轮或双指放大密集表格与几何标注。含明确字号且可可靠测量的 SVG 在弹窗初始 100% 下保留至少 12px 的阅读字号，宽图和长图可在弹窗内滚动，也可聚焦阅读区后使用方向键或翻页键，不受正文配图比例影响。使用「适应全图／阅读尺寸」切换键查看整体或恢复清晰字号；100% 对应当前模式的初始尺寸，切换模式会还原缩放。手动图片与无法测量的旧 SVG 仍按全图适配显示。缩放按图片内的位置定位，避免居中窄图因留白和内边距而突然偏向一侧；按钮以当前可见图片中心缩放，滚动到边缘时受实际边界限制。此规则也适用于裁剪器，裁剪区域仍按原图比例保存。关闭弹窗不会更改题目已保存的配图比例。
- **手机几何图阅读**：新生成的结构化基础几何、圆几何及坐标图根据完整图元和文字框减少外围空白，保留描边余量、题目坐标及横纵比例，在相同的手机页面可用宽度下可以显示更大的标注。旧配图保持原来的画布，重新生成后才应用。密集标注、长标题或很长的坐标轴仍可能需要「查看大图」，已有配图比例与位置设置继续生效。
- **圆弧和扇形**：模板支持优弧、劣弧和半圆方向，半圆用第三个圆周点指定经过哪一侧。圆周点有小幅径向坐标误差时按原方向对齐半径，校验和绘制使用同一投影；对齐后不同点名重合、弦退化成零长度或直径端点超出原有圆心容限时整图回退，不靠合并点名、删除线段或移动端点修补。不同方向的相邻点不因圆弧的方向阈值被当作重合点，文字能否排开仍单独检查。关系矛盾、方向不明或点位超出容差时尝试兼容旧 SVG，仍不可用时保留原图核对或手动配图。
- **方格图文字**：保留正方格、原有行列和涂色位置，按标签需要扩大方格及画布，格内文字最多三行，最低字号为 12；仍装不下时回退，不删除文字或挪到其它格子。密集网格可用「查看大图」放大检查。
- **数学标注保真**：保留 `cm²`、`m³`、`A₁`、`½` 等字形，仅转换全角 ASCII 并整理空白。方格、表格和图表换行时，常见数值、紧连算式及常用单位保持完整；宽度按 Unicode 字形簇估算，组合重音、变体选择符和连接符不重复计数。成对的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 公式，以及带完整参数的有限常见原始命令（包括 `\frac {1} {2}`、`\sqrt [3] {27}`、`\mathbb {R}`、`\operatorname {lcm}`、`\substack {a=1\\b=2}`、`\overset {?} {=}` 和成对的 `\left … \right`）不会被分词拆开，SVG 文本不执行 KaTeX；参数不完整、无法表示或装下时保守回退，不拆分数值或删除内容。复杂公式和复合图形仍需核对。
- **统计图范围与标注**：柱状图保留 0 基线，柱顶数据值与柱体、分类文字、标题、单位和坐标轴共同避让；折线图按实际数据及明确的 `minValue` / `maxValue` 排布，不把小数数据无条件补到 1，也不把全负数数据绘制成正数范围，数据值与线段和数据点共同避让。数值不能完整保留或无法可靠排版时回退完整旧图、原图或手动配图。
- **几何标注避让**：基础几何、圆几何和坐标图会为点名、线段长度、角度、扇形、圆弧文字和圆名共同选择可用位置，避开线段、圆周、角标记、点标记、固定说明及其它标注。线段、半径、直径和弦的文字按整个文字框大小在线段中部两侧排版，并检查与邻近线段的归属；半径文字的移动距离还会随半径长度限制。角度文字整体保持在所属角内、角标外侧及两条射线的有效长度内，扇形文字整体保持在原扇形内，圆弧文字位于对应圆弧外侧。优弧文字框也不能跨入被排除的劣扇形。圆名的整个文字框留在所属圆内；相交圆的名称不放在交叠区，同心圆的外圆名称留在圆环内，避免认错圆。标题、坐标刻度和自由说明保持原锚点；它们遮挡图元、其它文字或超出边界时明确回退。坐标图的浅灰背景网格不参与避让，坐标轴及题目线条参与。排版不会移动图形或删除标注；没有可靠空位或角标过小时回退旧 SVG，仍不可用时使用原图核对或手动配图。复杂图形和识别结果仍需检查。
- **配图显示比例与位置**：有配图的错题会在详情页显示此设置，可输入百分比或拖动滑块预览（10%～200%，默认 100%），并选择显示位置（居左/居中/居右，默认居中）；含配图的试卷也支持按题逐个调整或全卷统一调整配图比例与显示位置。点击「保存」后，刷新页面和文字打印都使用保存的比例与位置；「恢复 100%」可还原默认比例，再保存生效。SVG 与手动配图均只按比例缩放一次；宽图的占位由容器限制，避免窄图重复缩小。放大时以可用宽度为上限，保持宽高比。备份会保留此设置，旧题和旧备份默认 100% 且居中。打印预览中的「图片比例」用于拍照原图，打印配图时请勾选「原题文字」。
- **SVG 动画讲解**：按解题思路分步骤演示，打开页面或切换动画时停在首帧，须点击播放才开始，支持暂停、拖动进度、重播和全屏，个人设置默认开启。点击播放器上的喇叭开启语音讲解（默认关闭，开启后会记住），朗读每一步（默认用浏览器的语音合成；管理员开启云端语音后由服务端合成，所有设备音色一致），画面等语音读完再进入下一步（等待时停在当前步骤完整的画面上，动画外框高亮提示），语速可在 0.75×～1.5× 间切换。旧动画没有讲解稿时朗读画面底部的字幕；点击动画上方的「补充讲解稿」可由 AI 按现有画面补写讲解稿，画面不变，不需要重新生成动画（计 1 次 AI 动画讲解用量）。已有讲解稿时按钮显示为「重写讲解稿」。使用云端语音时，首次开启语音会一次合成整个动画的讲解语音，动画上方另有「重新生成语音」可重新合成；两者都会登记到「后台任务」中显示进度（消耗语音服务商额度，不计 AI 次数）。已生成云端语音的动画再次打开时默认开启语音讲解。动画文字跟随界面语言，中英文版本分别生成和保存，切换语言时自动显示对应版本。
- **GeoGebra 动态演示**：供数学、物理题生成交互图形，个人设置默认关闭。

已生成的动画和 GeoGebra 演示可在确认后删除。生成的图形和解答需要人工核对，尤其是几何位置、计数过程和结论。

- **直角条件归属**：通用几何与专用圆图只将紧邻对应角名的明确直角声明与坐标核对，不拿后一个角或后一句的条件代替。支持前置“直角”、英文 `right angle`、`90°`、`90.0度` 和 `90 degrees`，以及同一角连续声明类型与直角的写法。否定、提问、待证明和假设保持保守，不把 `190°` 或 `90.5°` 当作 `90°`，也不将四点长名称截成三点。明确冲突时整图或整组回退，原图、完整旧 SVG 和手动配图继续保留；不修改点位，不提供通用角度求解。

- **圆线段名称与说明**：半径、弦、直径只使用完整的两个规范点名。英文点名后接长度说明、点名前接 `Given` 等说明，或使用“AB 是一条弦”这类中文量词时，也会核对实际图形关系；保留数字、下标、撇号和大小写。后置关系的常见疑问、假设、引用和待证明语境不作为已知条件。三点长名称不截成两点，普通英文词内不匹配关系关键词。适用于通用与专用圆图，部分点名缺失、明确圆范围冲突及图组冲突仍沿用原有整图回退；不从自然语言说明计算长度或补写单位。
- **后置圆归属**：“AB 是圆 O 的弦”“AC 是外圆的一条直径”及 `AB is a chord of circle O` 只在指定圆上核对当前关系；完整圆名优先于圆心点名，重复圆名不能按端点或半径挑选。局部归属不传给后续线段，已有前置圆范围继续按原规则延续。常见疑问、假设和待证明内容保持保守，未标注的内外圆名不按尺寸猜测。明确冲突时整图或整组回退，保留原图和手动配图，不移动点或补线段。
- **题干长度与图内标注**：题干明确给出 `AB=5厘米`、`线段AB长5厘米` 或 `AB has length 5 cm` 时，结构化图中同端点且有明确标注的线段会逐项核对数值、单位换算和反向点名；重复标注必须一致。有限小数、普通分数、带分数及常用公制单位只在验证时换算，原文字保持不变；无单位数值只与其它无单位数值比较，不补缺失单位。公式片段、运算符后的子串、未知表达式、面积单位、疑问、假设和待证明说法不建立长度约束，不按坐标比例推算或补值；明确冲突整图或整组回退。

- **主图尺寸与方向**：明确主图声明后的长、宽、高、底、上下底、边长或棱长会与面积／立体模板的对应数值标签交叉核对，中文和英文前缀及“长宽高分别是4、3、2厘米”“底和高分别为6厘米和4厘米”、`length and width are 6 cm and 4 cm respectively` 或 `length, width, and height are 4 cm, 3 cm and 2 cm respectively` 等 2～4 项列表写法均支持。维度名和数值须数量相同、顺序对应；列表末项明确的共同单位只按列举语法用于此前无单位项，不推断其它缺失单位。未指定方向的矩形、长方体允许整体交换水平长宽，高和梯形上下底不随意互换；三角形顶点说明不是边长。深度只有图内也明确标注时才比较，不猜水平或竖直方向。其它物体、辅助线、跨平面／立体类别、疑问、假设或未知公式不强行套用尺寸；不补数值、不按坐标比例推物理长度。明确冲突整图或整组回退，原图与手动配图继续兜底。

- **圆柱和圆锥**：AI 重新生成配图、举一反三与试卷新题可使用 `round_solid` 模板绘制正圆柱和正圆锥。圆锥轮廓与椭圆底面相切，半径、直径和高使用各自尺寸线，母线沿斜边标注；程序核对已知半径／直径及圆锥勾股关系，并核对明确主图声明后的相应尺寸。原单位、分数和未知量保留，不补答案。极端比例、标注放不下或明确冲突时完整回退；不用于斜立体、圆台、展开图或组合体。上传识题仍不自动重绘，原图与手动配图保留，不增加模型请求。模板正确不代表原图识别无误，生成后仍须检查。
- **球体**：`sphere_geometry` 模板只表示完整球体，固定绘制圆形轮廓、前实后虚赤道和独立的半径／直径尺寸线；长英文、带分数和单位标注在线下固定排版，并保留与尺寸线的关联。半径和直径的明确数值按两倍关系校验，未知量不补值。半球、球壳、截面、挖孔、组合体和跨图大小比较不套用模板；语义冲突或标注无法完整排版时整图／整组回退，原图、手动配图和旧 SVG 继续可用。
