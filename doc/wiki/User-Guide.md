# 错题管理指南

旧安装的管理员仍使用默认密码时，先在安装向导完成改密。向导可读取安装状态，受限API返回JSON错误而不跳转成网页；后台任务按钮在向导和改密前隐藏。

## 创建错题本

创建错题本时选择学段（小学、初中或高中）和学科。学段与学科决定 AI 使用的知识点库，创建后不可修改，建议按学习阶段和学科分别管理。

小学可选数学、英语和语文。内置语文库覆盖小学一年级至六年级及初高中各年级的章节与知识点。升级 Docker 或安装包后，启动时会自动补齐缺失的内置语文标签，并保留旧标签 ID、题目关联、自定义标签和其他标签体系。

管理员导入「人教版课标体系」知识点后（见 [设置与用户管理](Settings-and-Users)），创建错题本时会多出「标签体系」选项。该体系与内置体系并存，创建后不可更改，AI 识别和知识点筛选只使用错题本所选体系的标签。

错题本列表只显示名称和题数，点击进入详情页；重命名和删除都在详情页进行。只能删除已清空的错题本，删除前先移走或删除其中的错题。

## 录入题目

| 入口 | 适用情况 |
| --- | --- |
| 图片上传、拖拽、拍照 | 纸质试卷、练习册和已有题目图片 |
| 剪贴板粘贴 | 已复制的截图或图片，使用 `Ctrl/⌘+V` |
| 屏幕截图 | 浏览器支持屏幕共享，且页面满足安全上下文要求 |
| 手动输入 | 已有文字题干，可使用 Markdown 与 LaTeX |
| 直接录入 | 手工整理已知的题干、答案和解析 |

图片可以先裁剪，裁剪和多题框选时可用鼠标滚轮、触屏双指捏合或右上角的按钮缩放（100%～500%，点击比例还原）；一张图片上有多道题时，可框选多题批量导入。尽量保留完整题干、必要图形和学生作答，避免模糊或裁掉条件。

一次选择多张图片时，裁剪窗口会显示当前张数，按选择顺序逐张旋转、裁剪；点击“确认并裁剪下一张”继续，最后点击“完成裁剪并导入”。默认“单题裁剪”下，所有图片共同组成一道题（例如跨页文章和问题），一次联合识别，只保存一道题及全部原图。只有主动选择“多题框选”时，各框才作为独立题目批量导入。本次模式在首张确认后保持一致；需要更改模式可取消后重新选择。中途取消会放弃尚未导入的裁剪结果。人工校对、原图查看和数据备份均保留图片顺序。

多图请求不会重复发送第一张图片，也不会额外降低图片分辨率。支持最多 20 张图片，每张编码后的传输数据不超过 20 MiB，合计不超过 50 MiB；服务端代理容量为 80 MiB，覆盖旧客户端重复首图和题目文字的传输开销。

在“设置 → 通用”开启“导入前人工确认”后，可先在校对页修改识别内容再保存。AI 可能识别错数字、符号和图形关系，保存前应核对原题。

## 学生答题与管理员查看

普通用户共享管理员题库与试卷，独立保存复习进度和答题结果。学生提交复习或试卷答案后，AI 批改并保存逐题判定与错因分析。

学生可在逐题结果的「我的答案」中核对自己提交的文字、选项或手写图片，重新打开最近一次提交后仍可查看。判分说明、错因分析、参考答案和解题说明支持 Markdown 与公式显示；参考答案和解析仅在该题批改完成后返回。

管理员进入「管理后台 → 用户列表 → 查看详情 → 学生答题记录」，在「复习记录」和「试卷记录」之间切换，查看历次提交时间、批改状态、正确数与正确率。点击「查看批改」可分页查看当次提交的题目快照、题图、学生文字或选择答案、手写图片、参考答案、解题说明、判分依据与错因分析；点击手写图片可放大。

正确率只统计已经成功批改的题目，等待中或批改失败的题目不会算作答错。点击「刷新」读取最新批改状态。查看记录只读取已保存的数据，不重新调用 AI，不需要学生重新提交；修改或删除源题目后，仍可查看已保存的题目与答案快照。此入口仅管理员可用。

## 自动判重

导入时会与当前用户的已有题目比较题干，跨错题本参与判重。默认阈值为 90%，可在个人通用设置中调整。

- 相似度**严格大于**阈值时，返回已有题目，并在原题下记录一次做错。
- 相似度等于阈值时，不按超过阈值处理。
- 相似度是规范化题干后的字符编辑相似度，不代表数学含义相同。
- 重复导入记录参与后续掌握情况评估；需要核对时可查看原题的作答历史。

错题本还提供两题相似度比较，便于判断阈值是否适合自己的题目。数字或条件只改动少量字符时，相似度仍可能较高，应结合题意判断。

## 题目详情

每道题集中展示题干、答案、解析、知识点、难度、学期和卷别，并可查看拍照原图。

| 信息或操作 | 说明 |
| --- | --- |
| 6 位题目 ID | 可复制，在错题本按 ID 定位；打印中显示为来源 ID |
| 1～5 星难度 | AI 参考竞赛数学难度标准评定，可手动修改 |
| 年级/学期 | 点击「编辑年级/学期」选择并保存；校对页也可修改，加载账户资料不会覆盖手工选择 |
| 卷别 | 未指定时，1～3 星默认归入「A卷」，4～5 星默认归入「B卷」；已有手动选择优先。可在「设置 → 通用 → 卷别分组」自定义分组名称、新增分组（如单元测试、期中、期末）、停用或删除自定义分组 |
| 知识点 | 使用对应学段与学科的标签，支持单题或整本重新识别 |
| 重新生成完整解答 | 生成新的答案和解析，覆盖前会要求确认 |
| 修复 LaTeX | 检测到公式语法问题时出现，供 AI 修正公式写法 |
| 原题图片 | 可查看、替换或补充，用于核对识别结果 |

未评级的题目不会仅凭默认规则自动指定卷别。重新生成完整解答保留知识点和错因信息。

![题干、知识点、难度与试题信息](https://raw.githubusercontent.com/margrop/wrong-notebook/70b66950931f6f723083e3726fbc97f2f65d2ea8/doc/screenshots/question-detail.png)

新题目的年级可以在「设置 → 通用」选择固定或 AI 识别规则，手工选择优先，详情见[设置与用户管理](Settings-and-Users)。

## 配图和动态讲解

- **整数位数条件**：题干明确“两位数”等整数位数时，已知值按绝对值核对，符号和前导零不算数位，`034`、`34.0` 均按 34 核对；`3.4` 不是两位整数，微小的非零小数部分也不会被舍入掉。配图仍保留输入原文；未知数字框沿用数位检查，复杂表达式不求值、不补答案。没有明确位数条件的小数竖式继续沿用原规则，此项不提供通用小数点对齐。
- **明确度量校验**：新结构化配图会核对正方形边长、正方体棱长、矩形和平行四边形上下边、同圆半径与直径，以及直角方框的明确度数。弦长不超过同圆已知直径或半径的两倍；同一对端点的线段即使反向标注或兼作弦和直径，明确长度也须一致，不要求不同的弦等长。整数、小数、普通分数及有限带分数支持常见公制单位的精确内部比较，保存的标签保持原文。无单位数只和其它无单位数比较，未知公式和角编号不求值；相对绘图尺寸及弦的示意角度不用于推算物理长度，也不补缺失单位。矛盾时整图或整组回退，旧 SVG 只做安全净化，仍需核对题干与原图。「AI 重新生成配图」没有可用输出时保留现有配图，后台任务显示失败并可重试。
- **题干与竖式交叉校验**：唯一完整的整数、小数算式或“两位数乘25”等条件会核对数字、正负号、运算符和两边的明确位数，支持常用 LaTeX 运算符和英文运算词。题首带明确标签且完整分隔的有效日期（如“日期：2026-11-15。”）、时间范围和题号范围不当作算式；仅限连续题首信息，正文、公式、无效日期或缺少分隔的内容仍保守处理。常用无参数样式（如 `\displaystyle`）和间距命令不取消数字核对，不改写原文或忽略有参数命令中的计算结构。小数精确比较，保存的原文不改变；不会把 `3.4×25` 截成 `4×25`，也不把分数斜线当作除法。含括号复合式、连续运算、未知式或多个候选时不截取推断。发现冲突时尝试完整旧 SVG，无可用结果则不返回新配图；原图、手动配图继续保留。此检查不提供通用公式求值或小数点对齐。
- **题干与主图交叉校验**：使用“下图是一个正方形”或“The figure is a square”等有限的直接声明时，程序核对面积图、立体图和可明确对应的单个通用多边形，接受等边矩形和等棱长方体等兼容画法。通用多边形可旋转、反向列点、保留共线中间点和内部辅助线；只核对完整等长边标注，不把分段或对角线当作整边，不按坐标比例求实际长度或移动原始点。梯形须只有一组对边平行。求值提问仍保留形状约束；形状疑问、命题判断、待证明、假设、引用、局部图、多形状、带圆、外部独立图元及图组不推断主图归属。明确矛盾时整张结构化图回退；仍须对照原图。
- **闭合线段主图**：没有 `polygons` 时，只有所有实线恰好组成一个简单闭合环才参与题干形状校验；开链、多环或额外实线无法明确主图时保守跳过，虚线内部辅助线可以保留，不会为校验改变线段。
- **三角形子类型**：主图的明确等腰、等边、直角及等腰直角声明同步核对面积模板和单个通用三角形。完整等长边须有一致标注；直角图三条完整边均有同类单位明确数值时精确检查勾股关系。未知表达式、分段、内部高、顶点说明不用于补边长或算答案，也不补单位。面积模板的 `apexRatio` 支持0～1，0和1可让直角位于底边端点，仅此时高也是完整边；坐标有限容差不放宽数值标签的精确比较。
- **竖式填空**：新生成的结构化竖式保留方框、问号、下划线和未知数字，不能因已知因数而自动填出答案。乘法部分积保留甲乙标签并按数位错开；位移重复或超出已知整数乘数的位数时整图回退。仅对已有的纯整数结果继续复算，不能据此证明原图识别正确；旧配图不会自动修改，旧 SVG 回退也不保证数学正确。
- **竖式阅读**：新生成的竖式按内容安排紧凑画布，整数和简单未知数字按固定列对齐，方框不会因字宽不同而挤乱数位。说明在完整运算下方，最多三行、字号至少 12px，装不下时整图回退，不截掉说明或挤到中间。长竖式仍可滚动查看；小数与复杂表达式保留整行文字，尚不支持通用小数点对齐。旧配图重新生成后才使用新布局。
- **SVG 配图**：常见图形由 AI 识别结构后使用本地模板生成静态 SVG，供详情、练习和打印使用；原图可单独查看。题目配图提供「查看大图」按钮，手机上可在大图弹窗中通过按钮、滚轮或双指放大密集表格与几何标注。含明确字号且可可靠测量的 SVG 在弹窗初始 100% 下保留至少 12px 的阅读字号，宽图和长图可在弹窗内滚动，也可聚焦阅读区后使用方向键或翻页键，不受正文配图比例影响。使用「适应全图／阅读尺寸」切换键查看整体或恢复清晰字号；100% 对应当前模式的初始尺寸，切换模式会还原缩放。手动图片与无法测量的旧 SVG 仍按全图适配显示。缩放按图片内的位置定位，避免居中窄图因留白和内边距而突然偏向一侧；按钮以当前可见图片中心缩放，滚动到边缘时受实际边界限制。此规则也适用于裁剪器，裁剪区域仍按原图比例保存。关闭弹窗不会更改题目已保存的配图比例。
- **手机几何图阅读**：新生成的结构化基础几何、圆几何及坐标图根据完整图元和文字框减少外围空白，保留描边余量、题目坐标及横纵比例，在相同的手机页面可用宽度下可以显示更大的标注。旧配图保持原来的画布，重新生成后才应用。密集标注、长标题或很长的坐标轴仍可能需要「查看大图」，已有配图比例与位置设置继续生效。
- **圆弧和扇形**：模板支持优弧、劣弧和半圆方向，半圆用第三个圆周点指定经过哪一侧。圆周点有小幅径向坐标误差时按原方向对齐半径，校验和绘制使用同一投影；对齐后不同点名重合、弦退化成零长度或直径端点超出原有圆心容限时整图回退，不靠合并点名、删除线段或移动端点修补。不同方向的相邻点不因圆弧的方向阈值被当作重合点，文字能否排开仍单独检查。关系矛盾、方向不明或点位超出容差时尝试兼容旧 SVG，仍不可用时保留原图核对或手动配图。
- **方格图文字**：保留正方格、原有行列和涂色位置，按标签需要扩大方格及画布，格内文字最多三行，最低字号为 12；仍装不下时回退，不删除文字或挪到其它格子。密集网格可用「查看大图」放大检查。
- **数学标注保真**：保留 `cm²`、`m³`、`A₁`、`½` 等字形，仅转换全角 ASCII 并整理空白。方格、表格和图表换行时，常见数值、紧连算式及常用单位保持完整；宽度按 Unicode 字形簇估算，组合重音、变体选择符和连接符不重复计数。成对的 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 公式，以及带完整参数的有限常见原始命令（包括 `\frac {1} {2}`、`\sqrt [3] {27}`、`\mathbb {R}`、`\operatorname {lcm}`、`\substack {a=1\\b=2}`、`\overset {?} {=}` 和成对的 `\left … \right`）不会被分词拆开，SVG 文本不执行 KaTeX；参数不完整、无法表示或装下时保守回退，不拆分数值或删除内容。复杂公式和复合图形仍需核对。
- **几何标注避让**：基础几何、圆几何和坐标图会为点名、线段长度、角度、扇形、圆弧文字和圆名共同选择可用位置，避开线段、圆周、角标记、点标记、固定说明及其它标注。线段、半径、直径和弦的文字按整个文字框大小在线段中部两侧排版，并检查与邻近线段的归属；半径文字的移动距离还会随半径长度限制。角度文字整体保持在所属角内、角标外侧及两条射线的有效长度内，扇形文字整体保持在原扇形内，圆弧文字位于对应圆弧外侧。优弧文字框也不能跨入被排除的劣扇形。圆名的整个文字框留在所属圆内；相交圆的名称不放在交叠区，同心圆的外圆名称留在圆环内，避免认错圆。标题、坐标刻度和自由说明保持原锚点；它们遮挡图元、其它文字或超出边界时明确回退。坐标图的浅灰背景网格不参与避让，坐标轴及题目线条参与。排版不会移动图形或删除标注；没有可靠空位或角标过小时回退旧 SVG，仍不可用时使用原图核对或手动配图。复杂图形和识别结果仍需检查。
- **配图显示比例与位置**：有配图的错题会在详情页显示此设置，可输入百分比或拖动滑块预览（10%～200%，默认 100%），并选择显示位置（居左/居中/居右，默认居中）；含配图的试卷也支持按题逐个调整或全卷统一调整配图比例与显示位置。点击「保存」后，刷新页面和文字打印都使用保存的比例与位置；「恢复 100%」可还原默认比例，再保存生效。SVG 与手动配图均只按比例缩放一次；宽图的占位由容器限制，避免窄图重复缩小。放大时以可用宽度为上限，保持宽高比。备份会保留此设置，旧题和旧备份默认 100% 且居中。打印预览中的「图片比例」用于拍照原图，打印配图时请勾选「原题文字」。
- **SVG 动画讲解**：按解题思路分步骤演示，打开页面或切换动画时停在首帧，须点击播放才开始，支持暂停、拖动进度、重播和全屏，个人设置默认开启。点击播放器上的喇叭开启语音讲解（默认关闭，开启后会记住），朗读每一步（默认用浏览器的语音合成；管理员开启云端语音后由服务端合成，所有设备音色一致），画面等语音读完再进入下一步（等待时停在当前步骤完整的画面上，动画外框高亮提示），语速可在 0.75×～1.5× 间切换。旧动画没有讲解稿时朗读画面底部的字幕；点击动画上方的「补充讲解稿」可由 AI 按现有画面补写讲解稿，画面不变，不需要重新生成动画（计 1 次 AI 动画讲解用量）。已有讲解稿时按钮显示为「重写讲解稿」。使用云端语音时，首次开启语音会一次合成整个动画的讲解语音，动画上方另有「重新生成语音」可重新合成；两者都会登记到「后台任务」中显示进度（消耗语音服务商额度，不计 AI 次数）。已生成云端语音的动画再次打开时默认开启语音讲解。动画文字跟随界面语言，中英文版本分别生成和保存，切换语言时自动显示对应版本。
- **GeoGebra 动态演示**：供数学、物理题生成交互图形，个人设置默认关闭。

已生成的动画和 GeoGebra 演示可在确认后删除。生成的图形和解答需要人工核对，尤其是几何位置、计数过程和结论。
